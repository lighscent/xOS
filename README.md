# xOS

simple 16-bit os with asm

## commands

- `help` - shows all commands
- `clear` - clears the screen
- `info` - shows system info
- `echo <text>` - prints text
- `layout` - shows current layout, `layout azerty` or `layout qwerty` to switch
- `reboot` - reboots
- `halt` - halts the cpu
